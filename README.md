# SOLO LEVELING : PLAYER SYSTEM
«Arise. Level up. Become the strongest version of yourself.»

A Solo Leveling-inspired personal task manager that transforms everyday goals into daily quests. Track your progress, earn experience, build consistency, and treat your real life like an RPG.

✨ Features

- 🎮 Player Dashboard: View your hunter profile, level, rank, and stats.
- 📜 Daily Quests: Turn daily goals into missions you can complete.
- ⭐ Experience System: Earn XP by completing tasks and track your progress.
- 🔥 Streak Tracking: Stay consistent and build better habits.
- 💠 System HUD Interface: A blue neon, game-inspired interface influenced by the Solo Leveling universe.
- 📊 Progress Tracking: Keep your goals visible and monitor your journey.

Features listed here should match what is currently implemented in the project.
